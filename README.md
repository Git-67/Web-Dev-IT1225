# Web-Dev-IT1225
**DISCRETION: This is a school project.**
## File Format
For all frontend stuff (HTML, CSS, JS), please maintain it all inside `/frontend`, while backend stuff (Python, Java, C#) should be in `/backend`, and database (SQL, PHP) should be hosted in AWS Incognito to maintain privacy of our collected data.
## Pushing Patches
Please push as a team and create a seperate branch when pushing with `git checkout`. Do not make changes for `/frontend` and `/backend` at the same time as it can cause merge issues.
